    How it works
    
        
    Agents decide what each line is. Code copies the text.
    
        
    
          
    1
    The Analyst reads the book
    It works out how this book is laid out and proposes a plan. The full run starts only after you approve it.
    
          
    2
    Labelers mark every line
    A few pages at a time, each line is marked as root text, commentary, heading or page header. They check their own work.
    
          
    3
    Code builds the rows
    The original text is copied into rows and numbered. The AI never writes or corrects a character.
    
          
    4
    The Reviewer takes a second look
    Anything uncertain is checked again. What is still in doubt is listed for you.
