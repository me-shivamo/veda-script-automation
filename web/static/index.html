How it works

Agents decide what each line of the book is. Code copies the text. No character is added, removed or changed.

  1. You give the book and say what you need. The OCR text, your request, and if you like the shape of the output file.
  2. The Analyst reads the book and shows you its plan. The sections it found, every kind of text and where it goes, and the output file as it will look. You approve it, correct it in your own words, or change the columns yourself.
  3. Labelers mark every line, a few pages at a time, as root text, commentary, heading, page header and so on, and check their own work.
  4. Code builds the output from the original text, and a Reviewer takes a second look at anything in doubt. What is still uncertain is listed for you.
